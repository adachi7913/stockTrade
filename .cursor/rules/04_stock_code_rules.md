# 銘柄コード管理の特殊仕様

## 基本ルール

本プロジェクトでは銘柄コードの管理に特殊な仕様があります：

- **companies テーブル**: 株価銘柄コードを5桁で管理（例: 13010, 130A0）
- **その他のテーブル**: 株価銘柄コードを4桁で管理（例: 1301, 130A）

## コード変換ルール

- 4桁→5桁変換: 末尾に「0」を追加（例: 1301 → 13010）
- 5桁→4桁変換: 末尾が「0」の場合は削除（例: 13010 → 1301）
- 最近では末尾に「5」がつく5桁コードの銘柄も存在

## 関連処理

1. companiesテーブルからコード一覧を取得時は5桁コード
2. 株価データや指標データのアクセスには4桁コードを使用
3. 業種名など企業情報が必要な場合は5桁コードで検索

## 実装箇所

- `StockRepository.update_market_cap()`: 4桁コードを5桁に変換してDB操作
- `StockRepository.fetch_market_cap()`: 4桁コードを5桁に変換してDB操作
- `StockRepository.fetch_industry_name_prefix()`: 直接5桁コードを使用

## 注意点

開発時は銘柄コードの形式に注意し、適切な変換処理を行うことが必要です。
